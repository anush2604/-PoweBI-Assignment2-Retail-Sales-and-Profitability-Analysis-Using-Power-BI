# PoweBI-Assignment2-Retail-Sales-and-Profitability-Analysis-Using-Power-BI

Developed an interactive Power BI dashboard to evaluate retail business performance through sales, profit, and target achievement metrics.

## Description
This project focuses on analyzing retail sales and profitability using Microsoft Power BI. It involves data modelling and DAX calculations to derive key business metrics. Calculated columns and measures are used to evaluate revenue, profit, and order counts. Interactive visualizations help compare actual sales with targets and track monthly trends. Product-wise and geographical analysis provides insights into sales distribution and performance. The dashboard supports data-driven decision-making through clear and meaningful visual reports.
